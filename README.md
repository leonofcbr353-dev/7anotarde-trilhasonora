# Equipe África — Sistema de Som

Sistema web desenvolvido para auxiliar na apresentação da **Equipe África — 7º Ano T**, permitindo controlar as músicas utilizadas durante a apresentação diretamente pelo celular.

## ✨ Funcionalidades

* 🎵 Reprodução das músicas da apresentação
* 🔄 Reprodução contínua das trilhas
* 🎚️ Transição suave entre músicas
* ⏹️ Controle para parar a reprodução
* 🔔 Indicador visual da música atualmente reproduzida
* 📱 Interface otimizada para dispositivos móveis
* 🌑 Interface minimalista em tema escuro
* ✨ Fundo animado e efeitos visuais sutis

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Web Audio / HTML Audio API

## 📁 Estrutura

```text
SoundSystem/
```

## 📱 Uso

O sistema foi desenvolvido com foco em uso durante a apresentação, podendo ser acessado através de um dispositivo móvel.

A interface foi projetada para que o responsável pelo controle de som consiga iniciar, trocar e interromper as trilhas rapidamente.
